# KoaZa Football Analytics — بسته منبع و ساخت ابری

این مخزن نسخه در حال توسعهٔ KoaZa است: رابط WPF، دریافت مسابقات از چند منبع، ذخیره محلی در SQLite، مدل پایه پواسون و تخمین برخی بازارهای آماری از تاریخچه پیاده‌سازی شده‌اند. آزمون گذشته‌نگر خودکار، کالیبراسیون احتمال‌ها و مجموعه آزمون‌های جامع هنوز لازم‌اند؛ خروجی‌ها تخمین هستند، نه تضمین نتیجه.

## نکته مهم درباره سازگاری ویندوز
- پروژه برای **.NET Framework 4.8** تنظیم شده است.
- برای اجرای برنامه باید .NET Framework 4.8 روی ویندوز نصب باشد؛ این بسته یک نصب‌کننده کامل یا برنامه self-contained نیست.
- Windows 7 فقط در صورت نصب Windows 7 SP1 و به‌روزرسانی‌های لازم ممکن است کار کند. سازگاری TLS/API و اجرای واقعی روی Windows 7 در این بسته آزمایش نشده است.
- کامپایل و اجرای این بسته در این محیط تأیید نشده است. گردش‌کار GitHub Actions برای ساخت روی Windows runner آماده شده است.

## ساخت ابری بدون نصب Visual Studio روی کامپیوتر شما
1. وارد حساب GitHub شوید یا حساب رایگان بسازید.
2. یک مخزن جدید بسازید (Repository)، مثلاً `KoaZa-CloudBuild`.
3. همه فایل‌های داخل این پوشه را در مخزن بارگذاری کنید؛ فایل‌ها و پوشه `.github/workflows` هم باید بارگذاری شوند. ساده‌ترین راه: در صفحه مخزن از **Add file → Upload files** استفاده کنید و فایل‌ها را از حالت ZIP خارج کرده، پوشه‌ها را حفظ کنید.
4. پس از ثبت فایل‌ها، به تب **Actions** بروید. گردش‌کار **Build KoaZa WPF app** باید اجرا شود. اگر درخواست تأیید Actions دیدید، آن را تأیید کنید.
5. وقتی اجرا با وضعیت سبز تمام شد، همان اجرای workflow را باز کنید و از بخش **Artifacts** فایل `KoaZa-Windows-Build` را دانلود کنید.
6. ZIP خروجی را استخراج کنید و `KoaZa.exe` را اجرا کنید. برای اجرای آن، .NET Framework 4.8 لازم است.

اگر ساخت شکست خورد، وارد همان اجرای Actions شوید و بخش قرمز build را باز کنید؛ متن خطا برای رفع مشکل لازم است. موفقیت ساخت ابری به‌تنهایی به معنی تأیید اجرای برنامه روی Windows 7 نیست.

## فایل‌ها
- `src/KoaZa/` — کد برنامه C# و رابط WPF.
- `src/KoaZa/Data/schema.sql` — طرح مرجع اولیه SQLite؛ ساختار نهایی و مهاجرت‌های سازگاری در `DatabaseService` نیز مدیریت می‌شوند.
- `.github/workflows/build-windows.yml` — ساخت خودکار روی Windows runner و بارگذاری خروجی.

## امکانات همین نسخه
- دریافت مسابقات از منابع پشتیبانی‌شده و محاسبه نرخ گل مورد انتظار از نتایج تاریخی ذخیره‌شده؛ در صورت کمبود تاریخچه، برنامه هشدار می‌دهد و ممکن است از میانگین پایه استفاده کند.
- محاسبه توزیع گل با پواسون و استخراج احتمال 1X2، Over/Under 2.5، BTTS و نتایج دقیق پرتکرار.
- ذخیره ورودی‌ها و احتمالات در SQLite محلی.
- رابط فارسی/انگلیسی، مدیریت محلی کلیدهای API با DPAPI، دریافت مسابقات، ذخیره تاریخچه و آمار منتخب، و محاسبه احتمال بازارهای منتخب پیاده‌سازی شده‌اند. ارزیابی Walk-forward، کالیبراسیون و آزمون‌های خودکار جامع هنوز در نقشه راه هستند.
