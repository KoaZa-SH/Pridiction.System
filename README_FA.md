# KoaZa Football Analytics — راهنمای فارسی

برنامه دسکتاپ ویندوزی برای دریافت مسابقات فوتبال، ذخیره محلی اطلاعات، بررسی آمار تاریخی و محاسبه احتمال بازارهای آماری است. برنامه با C#، WPF، ‎.NET Framework 4.8 و SQLite ساخته شده است. پیش‌بینی‌ها تخمینی هستند و نتیجه مسابقه را تضمین نمی‌کنند.

## دریافت مسابقات و ارائه‌دهندگان API

از بخش **Settings / تنظیمات** می‌توان سرویس‌ها را اضافه، فعال، غیرفعال یا حذف کرد. فهرست ارائه‌دهندگان شامل موارد زیر است:

- **API-Football (API-SPORTS)** — دریافت مسابقات و جزئیات در محدوده پوشش و سهمیه کلید.
- **Football-Data (football-data.org)** — دریافت مسابقات رقابت‌های پشتیبانی‌شده.
- **SportsAPI360** — دریافت برنامه مسابقات با شناسه رقابت یا مقدار \`all\`.
- **Football-Charts** — دریافت نتایج با شناسه متنی لیگ؛ کلید برای شروع الزامی نیست.
- **5DollarFootballAPI** — دریافت مسابقات و برخی آمار/رویدادها بر اساس طرح اشتراک.
- **OddsPapi** — دریافت مسابقات با شناسه مخصوص تورنمنت.
- **OpenLigaDB** — برای رقابت‌های پشتیبانی‌شده، بدون کلید.
- **Sportmonks**، **The Odds API** و **TheRundown.io** — در فهرست تنظیمات موجودند، اما اتصال مستقیم به قالب بومی این سه API هنوز پیاده‌سازی نشده است. برای استفاده، یک endpoint/proxy امن HTTPS لازم است که پاسخ را به قالب JSON نرمال‌شده زیر تبدیل کند.
- **Floodlight**، **Sports Open Data** و منبع دستی نیز با endpoint سازگار قابل تنظیم‌اند.

قالب endpoint سفارشی باید یک آرایه JSON یا شیئی با یکی از فیلدهای \`response\`، \`matches\`، \`fixtures\` یا \`data\` داشته باشد. هر ردیف باید نام \`homeTeam\` و \`awayTeam\` (رشته یا شیئی دارای \`name\`) و تاریخ در یکی از فیلدهای \`date\`، \`kickoff\` یا \`utcDate\` را ارائه کند. فیلدهای اختیاری شامل \`league\`، \`homeGoals\`، \`awayGoals\`، \`status\` و \`id\` هستند. هدر احراز هویت و نشانی HTTPS در تنظیمات قابل تعیین‌اند.

از **Import Fixtures / دریافت مسابقات** می‌توان منبع مشخص یا **Auto fallback** را انتخاب کرد. حالت خودکار منابع سازگار و فعال را امتحان می‌کند؛ پوشش واقعی به طرح اشتراک، سهمیه، شناسه لیگ و داده‌هایی که هر سرویس ارائه می‌دهد بستگی دارد. فعال‌کردن یک ارائه‌دهنده به‌تنهایی به معنی پشتیبانی از تمام لیگ‌ها یا همه آمارها نیست.

## تحلیل و بازارهای آماری

- استفاده از نتایج تاریخی ذخیره‌شده برای برآورد نرخ گل میزبان و میهمان و محاسبه احتمال‌های پایه پواسون.
- محاسبه احتمال برد میزبان، مساوی، برد میهمان، گل‌های کل، گل‌زدن هر دو تیم و نتایج دقیق پرتکرار.
- برآورد برخی بازارهای آماری مانند کرنر، شوت، شوت در چارچوب، کارت و آمار داور، فقط در صورت وجود نمونه تاریخی کافی.
- داده‌های جزئی مسابقه، از جمله آمار و رویدادها، در صورت دسترسی از API دریافت و در SQLite ذخیره می‌شوند. داده ناموجود به معنی صفر نیست.
- پنل اخبار از Google News RSS استفاده می‌کند؛ خبرها زمینه اطلاعاتی‌اند و رابطه علّی آن‌ها با نتیجه مسابقه تأیید نمی‌شود.
- رابط فارسی/انگلیسی و تنظیمات زبان در برنامه وجود دارد.

## امنیت و نگهداری داده‌ها

- پایگاه داده در پوشه محلی کاربر ویندوز نگهداری می‌شود.
- کلیدها در کد یا مخزن GitHub قرار نمی‌گیرند؛ تنظیمات کلید به‌صورت محلی با Windows DPAPI محافظت می‌شوند.
- کلیدهای API را در گزارش عمومی یا Pull Request قرار ندهید. اگر کلیدی افشا شد، آن را در پنل ارائه‌دهنده باطل و جایگزین کنید.

## ساخت و آزمایش

پروژه برای **.NET Framework 4.8** تنظیم شده است و گردش‌کار GitHub Actions برای ساخت ویندوزی دارد. آخرین وضعیت ساخت را از بخش **Actions** مخزن بررسی کنید؛ تا زمانی که اجرای مربوطه با موفقیت تمام نشده باشد، نباید موفقیت ساخت یا آماده‌بودن نسخه قابل‌حمل را فرض کرد.
